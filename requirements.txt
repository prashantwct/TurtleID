# Pinned. Unpinned dependencies break field re-deploys.

# Some pins are split by interpreter version. numpy, pandas and pillow ship
# compiled wheels built per Python version; a pin whose wheels predate the
# interpreter is not "an older version", it is a source build, and on a hosted
# runner without zlib/BLAS headers that build fails outright. Streamlit
# Community Cloud moved this app to Python 3.14, which is how pillow 11.0.0
# came to be compiled from source and stopped the deploy at
# "RequiredDependencyException: zlib".
#
# Both branches were resolved and installed clean on 3.10-3.14. If you add a
# pin here, check the wheel exists for the Python you deploy on.
